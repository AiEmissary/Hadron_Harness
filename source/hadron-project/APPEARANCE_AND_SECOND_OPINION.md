# Appearance and quick second opinions - Windows preview 0.4.9

Open Settings using the gear button. Appearance is near the top of the page.

- Hadron colours: Violet, Cream & Honey, Cocoa & Caramel, Rose Red or Ocean Blue.
- Display mode: Light, Dark or Follow system.
- Workspace text colour: Automatic follows the theme; High contrast uses black in light mode and white in dark mode; Custom exposes separate light/dark text colour pickers. Reset text colours returns to Automatic. This affects ordinary conversation text and headings; code, links, status colours and button labels keep their own colours.
- Fonts and typography: expand to use a supported Google Fonts link or a local font.
- Backgrounds and wallpapers: expand to upload/manage videos, choose backdrop colours and use the per-video Text setting. Opaque workspace panels cover most of the backdrop; video text settings differ from Workspace text colour.
The inherited advanced editor for unused widgets is not shown in Hadron Settings. Existing saved preferences and theme files are retained.

In Independent jobs, Get a second opinion appears beside each completed answer. It opens a clear pop-up and uses the OTHER agent: Agent B reviews A, or A reviews B. Confirm that agent's provider/model and click Evaluate. The question, answer and bounded earlier branch text form the review packet; sibling conversations, attachments and tool/folder permissions are excluded. Long inputs are explicitly marked as excerpts. No inference starts simply by opening the window.

A working indicator appears during evaluation. Close and continue with the original agent leaves its draft and selected branch in place. Closing does not cancel an active evaluation; Stop evaluation is separate. Reopen the same answer's button to recover/read the existing review without resending it. Reviews are saved as separate entries in the reviewing agent's history. Unknown start outcomes require Check evaluation; they are never automatically retried. This feature gives a quick text review, not verified consensus or a coding instruction.

The in-app How to use Hadron guide includes both locations and the second-opinion flow. Quit and reopen the development app to load rebuilt assets, or install the updated Windows executable for an installed copy. No personal profile, accounts or original application were changed by the fixture tests.

Hadron Settings now contains only Appearance, Connections, Agents and tools, Saved data, and Setup. Chat/Agent prompt modes, inherited provider credentials/defaults, compaction and reasoning defaults, LM Studio memory, legacy subagent/context/tool timeout controls, HTML cache, browser DevTools, remote access and ownership migration controls are not exposed. Hadron helper preference and its actual tool library replace the inherited controls. Optional Brave Search credentials remain because Hadron web_search uses them.

Settings scrolling (0.4.9): move the mouse over the content and use its wheel, or drag the visible scrollbar at the right. Section navigation and Back to top remain above the scrolling area. The content area supports keyboard scrolling when focused. Expanding font/background options does not push the navigation out of view.
