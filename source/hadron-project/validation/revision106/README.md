# Revision 106 - new-project copying, 30-day bin and colour palettes

Windows preview 0.4.6 combines the requested changes. Copy into project now offers Create new project and a name field. Project, reference chat, message and lineage creation are in one SQLite transaction. Failed copies cannot leave an empty project; identical retries return the existing result. Destination names are validated; copying to a recycled project is refused. Queries refresh the project and conversation lists. Help explains the new destination choice.

Local sidebar project/chat deletion now adds a durable Hadron Recycle Bin marker rather than immediately destroying records. Deleting a project hides its chats as well. Standard project, recent, paginated, favorite and title/message-search lists exclude marked items, and public lookup of a recycled project/chat returns unavailable so startup cannot reopen it automatically. Native IPC uses the actual local principal for listing and restoration. Restoring a project preserves original chat IDs, messages and relationships; separately deleted chats stay in the bin and require restoring their project first.

User-requested retention is exactly 30 days from the first deletion. Duplicate deletes do not extend it. Expired entries cannot be restored; cleanup runs on opening/listing/restoring the bin, startup, and hourly while the app is running. A closed app processes expiry on next start. Purge deletes the local project/chat records and normal cascading message records; this is not a secure erasure promise for historical job diagnostics or existing profile backups. Files in external project folders are not deleted. This only covers deletions made with the new version, not old permanent deletions. Cloud-record and individual-message deletion retain their existing behavior/confirmation.

Four new selectable Hadron palettes: Cream & Honey, Cocoa & Caramel, Rose Red and Ocean Blue, alongside Hadron Violet. Picker is in the workspace header and Settings theme controls. Choice persists locally and sets shared shell/button tokens, including dark surfaces. Choosing a palette disables conflicting advanced custom overrides; choosing an advanced custom theme clears the palette override. Existing theme files remain available. Help is updated.

Validation: six context-copy storage tests, four recycle/expiry tests and eight renderer tests including palette contrast and preference persistence. Production Electron/mobile/renderer typechecks/builds passed. Full owned desktop fixture passed existing and new-project copy, required name, sidebar deletion, native IPC restore with original message content, 30-day display, all four palettes across panes, and synthetic agent branching/review/history controls, with zero real provider requests. Private test fixture transitions were given an event-loop delay after navigation; one diagnostic script tried to return a function through Electron structured cloning and was corrected. No product guard was weakened. Final packaged diagnostic additionally requires live recycle-bin IPC and five palette options. No fresh clean-PC/installed-upgrade run is claimed for this pass; existing qualifications remain.
