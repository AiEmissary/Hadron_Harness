# Copy into a new project, recover deleted chats and change colours

Copy into project -> choose saved work -> Destination project -> Create new project -> enter a name -> Copy and open. The original remains saved; the new project opens with a reference chat containing the copied text. Files, active workers, tool/folder permissions and approvals are not transferred, and no AI request starts.

Open the left sidebar -> Recycle Bin -> Restore project or Restore chat. A deleted project and its chats remain recoverable for 30 days from deletion. Chats deleted separately stay in the bin when their project is restored. Expired items are permanently removed when Hadron next checks the bin; startup and hourly cleanup also run while Hadron is open. External project folder files are not deleted by this feature.

Open Settings (gear) -> Appearance -> Hadron colours. The workspace header no longer contains a palette picker. Choose Hadron Violet, Cream & Honey, Cocoa & Caramel, Rose Red or Ocean Blue. The choice is remembered. Text colours, display mode, fonts and backdrop options are grouped under Appearance.
