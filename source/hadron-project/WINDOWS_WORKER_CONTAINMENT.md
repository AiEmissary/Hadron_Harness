# Windows project worker containment - revision92

Project-only Codex commands and model-list processes now use a fixed Windows x64 native host. The build compiles trusted C# with the installed .NET Framework compiler and packages the executable and hash manifest. No runtime compilation or model-accessible launch endpoint is added.

The helper assigns the target to a non-breakaway kill-on-close Job Object during CreateProcess, before the target runs. Only duplicated stdio handles are inherited. A private control pipe binds preparation to the actual owning host. Exact parent/helper process creation times, Windows session ID and random job name are synced to private storage before launch acknowledgement. Cancellation, pipe-owner loss and helper death stop descendants. Job-name collisions refuse without terminating the existing owner.

Microsoft documents [Job Object lifecycle](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects), [startup attributes](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-updateprocthreadattribute) and [creation-time assignment](https://devblogs.microsoft.com/oldnewthing/20230209-00/?p=107812/). Inspection uses [OpenJobObject](https://learn.microsoft.com/en-us/windows/win32/api/jobapi2/nf-jobapi2-openjobobjectw) for query access only.

Saved-state inspection can report Windows-confirmed termination for newly recorded prior project-only Codex epochs. It compares exact process identities and kernel job accounting. A live original parent prevents an ended result. Denied queries, corrupt/missing evidence, another Windows session and unsupported systems remain unknown. More than256 records also remains unknown; retention/rollup is pending.

This contains process lifetimes, not filesystem or network access. Standard sessions, Claude helpers, unrelated writers and file-commit helpers are outside this transport. Observations cannot release execution markers, recreate old opaque leases, replay inference or apply files. Cross-process recovery retirement, project editing and commands remain disabled. Full packaging and Mac validation remain pending.
