# Project conclusions and continuing work

After preparing a project proposal, read Project conclusion at the top of the left pane. The Project conclusion button in the middle pane opens it again after inspecting a stage or file.

The panel shows the saved goal, Agent A recommendation, Agent B review, actual file/check states and suggested next step. A reviewed proposal is not an applied change, a passing test or proof that the whole project is complete. Long findings are explicitly marked as excerpts; the complete stages, diffs and logs remain saved.

Under Continue in another workflow, choose Work together for both agents, Independent / one-to-one for Agent A or Agent B, or Main chat. Press Use conclusion in new workflow. Add your next question to the editable draft, choose the required provider/models and press Start collaboration or Send when ready. Preparing the draft makes no AI request.

Work together and Agent A/B prepare separate new tasks with no old branch context or file attachments. Existing unsent agent drafts/attachments require confirmation before replacement. Active or uncertain jobs cannot be reset through this control. Main chat appends the summary to its current draft and uses its existing branch/context, rather than creating a new main-chat branch. Choose a new main chat first if you want an unrelated branch.

Only a bounded text summary and saved proposal ID cross the modes. Project files, folder permissions, tools and execution approvals do not transfer. Attach files or choose folder/tool access explicitly in the destination if needed. The original project proposal remains saved. Copy conclusion is also available.
