# Separate Windows PC acceptance test

Status: pending execution on the separate PC. No remote access has been configured.

1. Copy Hadron-Harness-0.4.9-win-x64.exe and this test-checklist folder to the other Windows x64 PC. Record its Windows version and whether Node, Git, VS Code or other development tools were already installed. A previously configured development PC does not establish clean-system compatibility.
2. Install using the normal installer and chosen directory. Retain any Windows or antivirus message. This preview is unsigned; follow that PC owner's security policy. No Electron or VS Code download should be required.
3. Open the desktop shortcut. Check the Hadron splash shows "Where AI's Collide" below the symbol for about four seconds, then the maximized workspace, three panes and How to use Hadron. Close Hadron before the diagnostic.
4. In Windows PowerShell, run `powershell -NoProfile -ExecutionPolicy Bypass -File .\Check-Hadron.ps1`. This bypass applies only to this invocation; it does not change the machine policy. If the shortcut has another name, supply `-HadronExe "C:\full\path\The Hadron Harness.exe"`.
5. Keep the reported temporary folder. It contains a startup JSON report, screenshot and Windows information. The diagnostic uses a separate empty profile, performs no sign-in or AI requests and changes no project files.
6. Reopen normally, connect your own account, and send a small question in Independent jobs. Test both agents, Work together and Continue with both agents. If using Claude, select its model and test it too. Never send passwords, codes or account files with the results.
7. Create a disposable local project, prepare a small reviewed change, inspect/apply it, then run a supported test. Confirm the status/output is visible. Save a chat, restart, reopen it, and verify no model request is replayed automatically.
8. Test Copy into project with an existing destination and with Create new project; confirm the reference opens and the original stays saved. Delete a disposable project/chat from the sidebar, open Recycle Bin and restore it; verify the original messages return. Confirm the bin explains the 30-day expiry. Open Settings -> Appearance and switch Hadron colours through Cream, Cocoa, Rose Red and Ocean Blue, then restart and confirm the selected palette remains. Scroll Settings down and up using the mouse wheel and the visible right-hand scrollbar, including with fonts/backgrounds expanded. Section navigation and Back to top must stay visible. Beside an independent answer, test Get a second opinion; close its popup and confirm the original draft/branch stays in place, then reopen the saved evaluation without another request. Test a short automatic conversation, Pause/continue and Stop. Check Help explains each mode.
9. If an older Hadron is already installed, back up its closed profile first and verify chats survive upgrading. A clean install and an upgrade are distinct tests. On this development PC, 0.4.0 to 0.4.1 and backup/recovery have already passed.
10. Uninstall only if wanted; Hadron user data should remain. Report success/failure, Windows version and any exact error. Share only the diagnostic report/screenshot after reviewing them; do not share the normal Hadron profile.
